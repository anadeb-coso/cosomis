{% load i18n %} {% comment %} Shared file-preview modal: any … on the page opens this modal instead of navigating away directly - the modal previews the file (PDF/image inline, otherwise just a "no preview" message) and offers Download / Open in a new tab / Close at the bottom. - data-url MUST already be the AWS-signed URL with its query string stripped (use the `imgAWSS3Filter` filter, i.e. `url|imgAWSS3Filter`) - the query string carries S3 request keys, not something to parse or persist. Used for the inline preview and "Open in a new tab" (a plain GET renders fine). - data-download-url should point to a Django endpoint that proxies the file back with a real `Content-Disposition: attachment` header (e.g. SupportingDocumentFileDownloadView) - a link to the S3 URL directly, even with the `download` attribute, does NOT force a download cross-origin: the browser just opens whatever it can render inline instead. Falls back to data-url if omitted (better than nothing, but won't force a download). {% endcomment %}
